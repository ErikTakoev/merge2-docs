# FillContainerLogic

[← На Головну](../Main.md) | [← До ChipInteractions](ChipInteractions.md)

`FillContainerLogic` — це реалізація `IChipInteractionLogic`, яка дозволяє фішкам взаємодіяти з контейнерами.

## Purpose
Дозволяє гравцеві перетягнути фішку-інгредієнт на фішку-контейнер для її наповнення та виконання завдань.

## How it Works

### Validation (CanInteract)
Система дозволяє взаємодію, якщо:
1. Обидві клітинки мають фішки і вони не є однією і тією ж фішкою.
2. Цільова фішка має компонент `ContainerModule`.
3. Контейнер не має заборон на заповнення (`container.Chip.BlockingState.CanBeFilled`).
4. Вихідна фішка є сумісною з цим контейнером (перевіряється через `container.IsChipCompatible(sourceChip)`).

### Execution (ExecuteInteraction)
При завершенні взаємодії:
1. Викликається `container.TryAddChip(sourceCell.Chip)`.
2. Якщо контейнер успішно прийняв фішку:
   - Вихідна фішка знищується всередині `TryAddChip`.
   - Контейнер оновлює свій внутрішній стан (або ініціює еволюцію, якщо всі вимоги виконано).
   - Метод повертає `true`.
3. Якщо додавання не відбулося (наприклад, через нестачу вільного місця для еволюції контейнера), повертається `false` і вихідна фішка повертається на місце.
