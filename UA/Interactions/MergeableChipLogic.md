# MergeableChipLogic

[← На Головну](../Main.md) | [← До ChipInteractions](ChipInteractions.md)

`MergeableChipLogic` — це основна реалізація `IChipInteractionLogic`, яка відповідає за злиття двох фішок.

## Purpose
Обробка процесу поєднання сумісних фішок для отримання результату нового рівня або типу.

## How it Works

### Validation (CanInteract)
Перед початком злиття система перевіряє:
1. Чи обидві клітинки мають фішки.
2. Чи не є вони однією і тією ж фішкою.
3. Чи має фішка, яку тягнуть, дозволи на злиття як джерело: `sourceChip.BlockingState.CanBeMergedAsSource`.
4. Чи має цільова фішка дозволи на злиття як ціль: `targetChip.BlockingState.CanBeMergedAsTarget`.
5. Чи має фішка, яку тягнуть, merge-конфігурацію: `sourceChip.MergeData != null`.
6. Чи дозволяє `sourceChip.MergeData` злиття з цільовою фішкою через метод `CanMerge`.

### Execution (ExecuteInteraction)
Коли злиття підтверджено:
1. **Визначення результату**: Отримується `MergeResult` через `sourceCell.Chip.MergeData.GetNextChip(mainCell.Chip.Data)`.
2. **Перевірка позиції**: Якщо фішка-результат більша за розміром (наприклад, [Multi-cell Chip](../Features/MultiCellChip.md)), система перевіряє, чи вписується вона в межі поля.
3. **Релокація сусідів**: Якщо нова фішка потребує більше місця, викликається система [Chip Relocation](../Features/ChipRelocation.md) для звільнення простору. Якщо звільнити місце на основній позиції не вдається, система автоматично перевіряє всі 8 сусідніх клітинок для пошуку альтернативного місця розміщення.
4. **Оновлення поля**:
   - Попередні фішки знищуються.
   - Створюється нова фішка через `ChipFactory`.
   - Запускається анімація `Merge`.
5. **Додатковий результат**: Якщо в налаштуваннях вказано `ExtraChip`, існує шанс появи бонусної фішки на сусідній вільній клітинці.

## Key Dependencies
- `ChipFactory`: Створення нових об'єктів.
- `IFieldGrid`: Робота з координатами поля.
- `IChipMovingLogic`: Переміщення сусідніх фішок при зміні розміру.
- `IFreeCellFinder`: Пошук місця для бонусних фішок.

> [!NOTE]
> Якщо `ExecuteInteraction` повертає `false` (наприклад, не вдалося розштовхати сусідів для великої фішки), `DraggableChipLogic` поверне фішку у вихідну позицію.
