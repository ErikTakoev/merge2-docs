# MergeableChipLogic

[← На Головну](../Main.md) | [← До ChipInteractions](ChipInteractions.md)

`MergeableChipLogic` — це основна реалізація `IChipInteractionLogic`, яка відповідає за злиття двох фішок.

## Purpose
Обробка процесу поєднання сумісних фішок для отримання результату нового рівня або типу.

## How it Works

### Validation (CanInteract)
Перед початком злиття система перевіряє:
1. Чи обидві клітинки мають фішки.
2. Чи не є вони однією і тією ж фішкою.
3. Чи має фішка, яку тягнуть, дозволи на злиття як джерело: `sourceChip.BlockingState.CanBeMergedAsSource`.
4. Чи має цільова фішка дозволи на злиття як ціль: `targetChip.BlockingState.CanBeMergedAsTarget`.
5. Чи має фішка, яку тягнуть, merge-конфігурацію: `sourceChip.MergeData != null`.
6. Чи дозволяє `sourceChip.MergeData` злиття з цільовою фішкою через метод `CanMerge`.

### Execution (ExecuteInteraction)
Коли злиття підтверджено:
1. **Визначення результату**: Отримується `MergeResult` через `sourceCell.Chip.MergeData.GetNextChip(mainCell.Chip.Data)`.
2. **Перевірка позиції**: Якщо фішка-результат більша за розміром (наприклад, [Multi-cell Chip](../Features/MultiCellChip.md)), система перевіряє, чи вписується вона в межі поля.
3. **Релокація сусідів**: Якщо нова фішка потребує більше місця, викликається система [Chip Relocation](../Features/ChipRelocation.md) для звільнення простору. Якщо звільнити місце на основній позиції не вдається, система автоматично перевіряє всі 8 сусідніх клітинок для пошуку альтернативного місця розміщення.
4. **Знищення та вирахування затримки**:
   - Чіп-джерело (`sourceMainCell`) знищується негайно.
   - Цільовий чіп (`mainCell`) ініціює своє знищення (`Destroy(mainCell, false)`), повертаючи тривалість своєї анімації руйнування (`destroyDelay`).
5. **Оновлення поля**:
   - Новий чіп створюється через `ChipFactory`. Якщо чіп став більшим, йому передається `parentWorldPosition` (позиція цільового чіпа) та `ChipFlightSettings.ChipGrow`, а його створення/поява відкладається на час `appearanceDelay: destroyDelay`.
   - Залежно від зміни розміру надсилається тригер аніматора `MergeGrow` (якщо чіп збільшився) або `Merge` (якщо розмір залишився незмінним).
6. **Додатковий результат**: Якщо в налаштуваннях вказано `ExtraChip`, існує шанс появи бонусної фішки на сусідній вільній клітинці із налаштуваннями польоту `ChipFlightSettings.ChipGrow`.
7. **Візуальний зворотній зв'язок (Feedback)**: Успішне злиття активує систему зворотного зв'язку перетягування (`IDragFeedback`). Спеціальний компонент `MergeLightDragFeedback` автоматично отримує сповіщення про завершення перетягування з успішною взаємодією і тригерить ефект `MergeLight` на результуючому чіпі.

## Key Dependencies
- `ChipFactory`: Створення нових об'єктів.
- `IFieldGrid`: Робота з координатами поля.
- `IChipMovingLogic`: Переміщення сусідніх фішок при зміні розміру.
- `IFreeCellFinder`: Пошук місця для бонусних фішок.

## Result Calculation: Weighted Random

`ChipMergeData` визначає всі можливі результати для кожної пари фішок через структури:

1. **`MergeCombination`**: Правила для пари фішок
   - **`TargetChip`**: Який партнер потрібен
   - **`Results`**: Список можливих результатів з вагами

2. **`MergeResult`**: Описує один можливий результат
   - **`Result`**: Яка фішка матиме бути
   - **`Weight`**: Вага цього результату (int)
   - **`ExtraChip`**: Опціональна бонусна фішка

3. **`ExtraChip`**: Опціональна бонусна фішка
   - **`ChipData`**: Що спавнить  
   - **`Chance`**: Шанс появи (0-100%)

### Algorithm

Система використовує алгоритм **Weighted Random Selection**:
1. Збираються всі `Results` для пари (sourceChip, targetChip)
2. На основі їхніх `Weight` обирається один результат випадково
3. Якщо один результат - він гарантований
4. Якщо нема результатів для цієї пари, злиття неможливе (CanInteract повертає `false`)

## Extra Chips

Якщо `ExtraChip` визначена у `MergeResult`:
1. Система генерує випадкове число (0-100)
2. Якщо число ≤ `Chance`, фішка спавниться
3. Місце спавну: найближча вільна сусідня клітинка (via `IFreeCellFinder`)
4. Якщо вільною клітинок нема, бонус не з'являється

> [!NOTE]
> Якщо `ExecuteInteraction` повертає `false` (наприклад, не вдалося розштовхати сусідів для великої фішки), `DraggableChipLogic` поверне фішку у вихідну позицію.
